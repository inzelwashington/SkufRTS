# Озвучка

117 реплик: 42 у скуфов, 40 у альтушек, 35 у диктора.

Синтезированы локально нейросетевым **piper**, тремя разными голосами:

| Кто | Модель | Подача |
| --- | --- | --- |
| Скуфы | `ru_RU-dmitri-medium` (мужской) | `length_scale 1.12` — медленнее |
| Альтушки | `ru_RU-irina-medium` (женский) | `0.93` — быстрее и звонче |
| Диктор | `ru_RU-denis-medium` (мужской) | `1.03` — ровная дикторская |

Тексты — `scripts/voice-lines.json`, генератор — `scripts/gen-vo.py`, манифест —
`manifest.json` рядом с этим файлом (его читает игра).

Каждая дорожка при генерации подрезается по тишине и выравнивается **по RMS**
(не по пику): у коротких выкриков вроде «Ну» пик высокий, а энергии мало, и по
пику они получались заметно тише длинных фраз. После выравнивания RMS у всех
файлов одинаковый, поэтому в бою голос звучит ровно и не тонет под музыкой.

## Перегенерировать

```powershell
node scripts/fetch-py-deps.mjs   # распаковать piper и его зависимости
node scripts/fetch-voices.mjs    # скачать три голосовые модели (~180 МБ)
python scripts/gen-vo.py         # переозвучить всё
```

Модели и сам piper лежат в `vendor/` и в репозиторий не попадают — они нужны
только в момент генерации. Игра просто проигрывает готовые WAV.
